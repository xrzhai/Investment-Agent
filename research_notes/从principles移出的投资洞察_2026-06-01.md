# 从 principles 移出的投资洞察

日期：2026-06-01
来源：`config/principles.md` 瘦身清理

> 本文保存从原则主文中移出的阶段性 / 行业性 / 解释性洞察。它们有参考价值，但不是跨周期硬原则。未来如果某条洞察被多次验证、确实会改变长期动作，再考虑提炼成一句原则。

---

## 1. 中国资产筛选器

阶段性偏好：现阶段中国资产不作为默认主线；优先研究能把中国供应链、工程能力、资源禀赋转化为全球现金流，或具备全球定价属性的公司。

纯内需资产默认谨慎，尤其是需求依赖居民信心、政策 / 分配规则不清、股东回报不确定的消费与平台类资产。招行这类国内金融基础设施只作为低估值、高分红、证伪条件清楚的小仓位例外，不作为中国资产主线。

保留方式：这更像当前研究偏好 / 组合暴露约束，不适合作为永久原则。

---

## 2. AI 平台与模型/API 层

### AI 平台选择权

同样是高质量科技平台，若当前估值已较充分，需要比较其 AI 叙事是在防守既有现金流，还是打开新的物理世界 / 机器人 / 具身智能等 TAM。

后者若商业化路径和生态控制力更强，即使估值不低，也可能拥有更高的选择权生成率；但不能用远期想象替代当前估值纪律和 IC。

### 模型 / API 层只给第一梯队溢价

模型公司或 AI API 的价值不能从 token 用量线性外推。低价值、通用型任务会被开源模型、模型路由、缓存和价格战压到商品化。

只有同时具备 frontier intelligence、成本效率、分发入口、开发者生态或企业 workflow 重力的第一梯队，才可能把 API 卖出溢价。组合表达上，二三线纯模型暴露默认不进核心仓；优先看同时拥有算力 / 数据 / 分发 / workflow / 安全边界的公司。

保留方式：这是 AI 行业研究框架，适合放在 AI/token economics/Agent workflow 的 research note 或 coverage，不放总原则。

---

## 3. 消费品牌与渠道系统

消费品牌商默认不是长期核心仓，除非它拥有跨周期社交共识。消费者心智和渠道媒介变化太快，大多数品牌商更适合按 3-5 年经营周期、设计 / 产品 / 库存 / 折扣 / 渠道修复来研究，不应直接当作永续复利资产。

长期核心消费资产优先看能熨平品牌周期的大渠道 / 平台 / 会员制零售，例如 Amazon、PDD、Costco、Walmart 这类持续享受消费总量增长和交易确定性的系统。

品牌商例外也要分层：
- 可口可乐更像全球日常习惯 + 分销网络；
- Hermès 更像全球顶奢稀缺共识；
- 茅台更像中国语境下的 See's Candies / 喜诗糖果：高 ROIC、高定价权、强礼赠 / 宴请 / 身份场景，但文化 / 政策变量和代际接受度更集中。

保留方式：这属于消费行业研究洞察，未来应进入消费/零售研究笔记或具体 coverage。

---

## 4. 优质资产的“鬼故事”入场

对已被市场广泛认可的高质量平台 / 基础设施资产，不必在无折价时强行追。更好的击球点常来自市场把一个阶段性风险讲成结构性崩坏的时刻。

关键不是机械抄底，而是提前定义鬼故事是否真的伤害长期 thesis。例如 AI infra 标的中，hyperscaler capex 放缓本身不是 IC；只有 capex 放缓同时证明客户 ROI 不成立、推理需求接不住、或平台抽税权下降，才构成 thesis 失效。

保留方式：这是买点方法论，可在开仓 checklist / coverage valuation 部分使用；总原则里只保留“好公司也要买得别太贵”。

---

## 5. 押注要诚实标注为押注

面对 META AI capex 这类难以短期证实的长期投入，可以选择相信管理层和战略伏笔，但不能把“我选择押注它有意义”写成“它一定有意义”。

Coverage 应区分：
- 事实证据；
- 弱信号；
- 管理层叙事；
- 我的主观信任。

并写清后续哪些经营结果会把押注升级为证据，哪些结果会迫使降级。

保留方式：原则主文已保留“thesis 必须可证伪”和“模型暴露假设”；这里作为 coverage 写作提醒。

---

## 6. 常识赔率与高频跟踪

当一家生意的赚钱方式能用朴素语言解释、现金利润大体可信，且价格已低到接近 3 年左右 owner earnings 回本时，“便宜是硬道理”本身就是核心信号。

不要因为缺少高频催化剂、无法精确跟踪每个季度，就否定赔率。高强度跟踪不能替代安全边际；但“便宜”只在现金真实、结构性衰退 / 治理 / 政策 / 资本配置风险不足以吞掉回本期时成立。

保留方式：这条接近底层原则，但细节太长。主原则里保留“相信常识”和“好公司也要买得别太贵”，这里保留展开。

---

## 7. 公开表达作为外部监督

公开发表投资原则或心路可以提高冲动操作成本，但不能替代 thesis / IC / 仓位纪律。

写公开观点或重要买卖前，可以留下：当前判断、收益来源、关键商业假设、主要财务代理变量、最强反方观点、反证信号、仓位纪律、下次复盘触发器。

保留方式：主原则只保留一句“公开表达不是风控替代品”；这里保留操作性 checklist。
