**日期：** 2026-06-17
**标签：** `#AMZN` `#Anthropic-IPO` `#SOTP` `#AI-Infrastructure` `#卖水人`

## 1. 核心催化剂

Anthropic 于 2026-06-01 秘密递表 SEC（TechCrunch/CNBC/Reuters 确认）。H 轮 5/28 完成 $65B 融资，投后估值 $965B（超 OpenAI 的 $852B）。市场预期 IPO 可能在 10 月，具体日期尚未确认。

## 2. 参与路径：通过 AMZN 间接持有

不做多单点模型公司（Anthropic 直接 IPO 不确定性高），通过 AMZN 间接参与：

**Amazon 的 Anthropic 敞口：**
- 持股：SEC 披露 ~7.8%，Fortune 推算含 convertible/preferred 在 "mid-to-high teens"（15-18%），对应 $965B 估值下价值 $135-174B，折合每股 $13-16
- $100B 算力承诺：Anthropic 承诺 10 年内向 AWS 采购 $100B+ 算力（4月协议），锁定远期 AWS 收入
- $50B OpenAI 算力合同（2月协议）：同时押注两个主要模型

**核心判断：**
- AMZN 比直接买 Anthropic pre-IPO 份额更安全——它是 "AI 基础设施的投资组合"（AWS + Trainium + 双边模型合作），下行有零售/AWS/广告稳定现金流保护
- "卖水人"逻辑比 "持股重估"逻辑更强：$100B 算力协议带来的 AWS 收入可见度提升 + 倍数扩张是 SOTP 重估主要驱动力
- IPO event 会迫使市场重新审视 AWS 在 AI 时代的基础设施定价权

## 3. 关键跟踪指标

- 10 月 IPO 前 S-1 招股书公开（关注关联交易占比、Amazon 实际持股比例）
- AWS Bedrock 企业级 API 实际调用量增速
- 2026 年底 $200B CapEx 的 ROIC 表现
- Anthropic $100B 算力承诺的执行细节（刚性 vs 意向性）
- 反垄断风险（Amazon 是最大股东+最大供应商+芯片独家供应商的垂直整合结构）

## 4. 讨论要点

**关于模型公司的结构性因素讨论：**
- 支撑 Anthropic 到 $965B 的核心因素：① AWS 飞轮（资本循环自洽）；② 安全叙事作为人才护城河（但 IPO 前正在快速衰减）；③ 模型能力梯队位置（Claude Code 有口碑但差距收敛中）；④ IPO 定价本身不确定性高；⑤ $100B 算力承诺的可执行性（最脆弱但关键）
- 企业端 AI 调用可能比 C 端更强——LLM 的边际成本结构不同于互联网（inference 有真实成本），C 端 $20/月订阅难形成规模，企业端有清晰 ROI

**关于买入方式：**
- 当前 AMZN ~$246（6/16），从 5 月高点 $262 回调 ~6%
- 倾向用现金买入 + 新增现金，不砍现有持仓（绝大多数持仓浮亏中，砍浮亏换新头寸不合理）
- 计划轻仓起步，慢慢加，不急于一次性建仓

**争议/待验证：**
- Q1 已披露 $12.3B "other income" 来自 Anthropic 重估，市场并非完全未定价
- "隐性期权"定性需要弱化——更准确的定性是 "已部分定价但存在上行空间的事件驱动因子"
- $200B CapEx 是双刃剑，如果 AI 推理需求增速低于预期，ROIC 压力大
