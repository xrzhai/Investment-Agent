# Thesis Review

## Goal

Pressure-test the current thesis against evidence available as of a declared date.

## Context

Load the current thesis, active facts, disputed facts and source metadata. Exclude portfolio state and subsequent evidence beyond the as-of boundary.

## Review questions

1. Which original claims remain supported?
2. Which were weakened or falsified?
3. Did definitions, reporting segments or comparison periods change?
4. Which apparent miss/beat is actually noise, seasonality or accounting timing?
5. Are invalidation conditions CLEAR, WATCHING, TRIGGERED or UNVERIFIABLE?
6. What evidence would change the conclusion next?

## Output

Write an evidence table followed by the conclusion. Do not recommend a trade; escalate to `decision.md` only if the user wants a position action.
