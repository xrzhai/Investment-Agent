# 投资原则

> 这是我的个人投资原则文档，只放跨周期、底层、会约束未来动作的原则。
> 阶段性市场判断、行业洞察、个股例子和交易解释，应放在 `coverage/`、`reviews/decisions/` 或 `research_notes/`，不要塞进原则。

---

## 0. 使用说明

- 原则是约束，不是文章；少就是多。
- 硬约束优先于偏好：能力圈、thesis、估值、仓位、现金、杠杆和 IC 优先级最高。
- 具体数字以 `config/profile.json` 和当日 portfolio tools 为准；本文件只解释为什么要这样管。
- 任何 thesis 都必须可证伪：如果正反事实都能被解释成利好，说明它不是投资判断。

---

## 1. 选股原则

- **看得懂**：能用简单语言解释公司如何赚钱、为什么能持续赚钱；解释不清，不进核心仓。
- **生意要足够好**：优先研究具备定价权、网络效应、高切换成本、规模优势或其他可持续稀缺性的公司。
- **稳定需求的默认入口**：真正能熨平周期的资产，通常不是持续押中新产品，而是占据一个长期、重复、低弹性需求账户的默认入口，并能把这种位置转化为提价权和自由现金流。C 端可能表现为心智 / 习惯 / 心理账户，B 端可能表现为工作流嵌入、数据、网络效应或切换成本；判断时重点问：需求是否不依赖新鲜感、用户是否不再重新选择、收费是否不破坏需求。
- **相信常识**：先问客户是谁、客户付钱买的是什么变化、稀缺性来自哪里、5-10 年后还能不能创造选择权。
- **质量优先**：偏好已证明的高质量公司；“第一 / 唯一”只是筛选器，不是买入理由。
- **默认降权的生意**：强周期、重资产、同质化、议价权低的公司必须提供额外补偿，例如更清楚的成本位置、更厚安全边际或更强定价权。
- **强周期不做长期持有**：周期资产的定价由它控制不了的变量决定，长期持有只增加波动、不增加补偿。这类资产的定位是“有退出期的配置”（逢高清、到期清），不占核心仓。（唯一例外是自认能完成“底部买入—顶部卖出”的完整周期套利的仓位，那属于周期反转/交易，不属于长期持有。）
- **不懂不碰**：无法理解商业模式或风险结构的资产，不投资；好公司但不在能力圈，也只能小仓、观察或退出。

## 2. 开仓原则

- **Thesis 先行**：开仓前必须写清投资逻辑、收益来源、估值区间、时间期限和失效条件。
- **入场必须能答“为什么十年不卖它”**：因为默认不减持（见调仓原则），买入标准要按“永久持有”的规格来。答不出“十年不卖”的，要么归入有退出期的配置（并写明退出条件），要么不进仓——不允许存在既答不出长期持有、也说不出退出日期的仓位。
- **买入理由来源审查（用户身份 ≠ 投资理由）**：喜欢一个产品、是它的长期用户，是关于**产品体验**的信息，不是关于**定价权和再投资能力**的信息。任何“我是它的用户/粉丝”的标的，入场前必须额外走一遍完整 thesis 检查（收益来源、估值区间、失效条件），不允许用体验代替判断。
- **好公司也要买得别太贵**：伟大公司不能自动抵消过高价格；“我相信未来”不等于“当前价格值得买”。
- **30x PE 上限（NVDA 例外）**：除非公司像 NVDA（极低 PEG + 极高确定性 + PE 能快速回到合理位置），否则不买 30x+ PE 的公司。高 PE 叠加业绩不确定性 = 戴维斯双杀的不对称下行风险；安全边际不够厚时，估值本身就是叙事。PEG 低、确定性强、PE 能快速回归，三个条件缺一不可。
- **区分增量买入与历史持仓**：巴菲特 / 伯克希尔这类巨型资本的长期持仓动作，往往包含历史成本、税延、资金容量、替代资产稀缺和稳定现金流需求；不能直接推出“今天新钱也该买”。个人组合更灵活，应按当前价格、目标回报、机会成本和可替代资产重新评估。
- **先定义赚哪种钱**：基本面成长、估值重估、分红/回购、周期反转、恐慌均值回归、交易/反身性，不能事后切换叙事。
- **商业分析先于财务代理**：先理解客户价值、稀缺性和现金流机制，再用财务指标验证；没有商业解释的漂亮财务，不作为重仓依据。
- **模型暴露假设，不制造确定性**：模型至少要有 Base / Bear / Break，用来暴露变量和承受力，不是假装精确预测。
- **确定性必须可承受**：高确定性 = 长期逻辑清楚 + 当前价格未明显透支 + 风险可承受 + 反证条件明确。

## 3. 组合原则

- **资产两类分法**：买入时就确定类别——**A 类：可永久持有的股权**（适用“不减持”）；**B 类：有退出期的配置**（入场时即写明退出条件，如逢高减、或明确日期上限）。这不是“不减持 + 例外清单”，而是两类资产用两套规则；B 类从来不在不减持的范围内。
- **B 类有组合上限**：B 类（有退出期的配置）合计不超过组合 25%，任一 B 类单标的 ≤ 10%。超线的动作不是立刻机械砍仓，而是禁止新增 + 任何一档退出触发时优先减 B 类；超过一个 review 周期仍未回到线内则机械减仓。理由：B 类权重会因自身上涨而被动升高（2026-08/09 实测：五周内 B 类权重 26.5% → 31.2%，涨的是 B 类自己，A 类几乎原地），"等被入金自然稀释"依赖核心仓涨得更快，不可依赖。
- **适度集中**：持仓数量控制在 5-15 个；单一持仓不超过组合 25%。
- **现金是选择权**：没有高确信度机会时允许持有现金，不强迫满仓。
- **仓位由可承受的不确定性决定**：仓位不是信仰浓度，而是由理解程度、反证清晰度、下行承受力、流动性和相关性共同决定。
- **核心仓必须是自己打穿的孔**：大仓位必须能说清怎么赚钱、为什么能持续、估值靠什么回本、什么事实会证明自己错。
- **管理相关性——用重验频率，不用权重上限**：多个仓位若由同一条因果假设支撑（例如 NVDA / GOOGL / META 共享“算力需求无穷无尽”），**不对该“因子”设硬性权重上限**——事后相关性推出的因子会误伤“同一趋势下的多个独立机制”（需求端重叠、回报机制不重叠）。正确做法是对这条共享假设**提高证据标准与重验频率**，写明可观测信号（如 hyperscaler capex 同比、单位推理成本、自研 ASIC 份额、订单可见性），并对这些信号做定期跟踪。判断依据是买入理由的正向因果，不是事后价格相关性。
- **体系隔离**：核心长期仓、机会加仓、cash-secured put、小交易/情绪价值仓必须各自有规则，不互相补锅。

## 4. 调仓原则

- **默认不减持**：长期仓（A 类）默认不卖，且不设例外清单——不减持的真正价值是**抬高买入门槛**，不是压低卖出频率。它的代价是删掉了“纠错”这个动作，所以必须由入场标准（见开仓原则）兜底。
- **加仓四条件**：thesis 完好、价格合理、基本面无恶化、当前权重未达上限。
- **加仓的上限与理由约束**：不减持不等于可以无限加仓。加仓仍受权重上限、相关性约束和“可承受的不确定性”约束；加仓理由必须是“这门生意便宜且我看得懂”，**不能是“为了让组合更分散”**——分散是结果，不是理由。
- **减仓不等于看空**：估值过高、thesis 出现裂缝、出现更好机会、权重过高或组合风险约束变化，都可以减仓。
- **不为动作感交易**：没有清楚理由时，等待本身就是动作。
- **调仓必须记录理由**：每次重大买卖都要能回看当时的信息集、动机和反证条件。
- **不参考成本价**：买卖只看当前 thesis、未来赔率和组合约束，不受沉没成本影响。

## 5. 离场原则

- **IC 触发，立即退出**：IC 是 thesis 失效的具体化，不分批拖延。
- **不减持 ≠ 免检**：结构性变化（不是波动）发生时，IC 触发优先于“不减持”；“十年不卖”的前提仍然是这门生意还在。
- **B 类按数值化的退出条件执行**：B 类资产在入场时就要写明退出条件，并且写成数字，不套用 A 类的长期持有逻辑。
  - **有资产端的（周期资源股、资产壳型）写价格条件**：锚在 coverage 的 Base / Bull 情景值上——**Base = 减仓线、Bull = 清仓线**，线随每次覆盖更新滚动（引用值，不是写死值）。
  - **无资产端的（无分母投机资产）不写价格条件**：它没有"贵"的定义，只有"敞口大"的定义——改写组合权重上限 + 下行证伪线。
  - 数字是提前兑现通道，硬时间上限不可因"还没到价"而延期。
- **清仓需要足够理由**：thesis 失效、当前持仓吸引力显著下降且有更好机会、或组合风险约束变化；单一理由通常不够。
- **不要把非 IC 减仓包装成价值投资清仓**：风险预算、估值过高和现金需求可以诚实写成 trim / rotate。

## 6. 风控原则

- **禁止加杠杆**：不使用融资融券或任何形式的杠杆工具。
- **衍生品仅限全额覆盖的简单期权**：禁止裸期权、杠杆期权、期货、融资融券、价差组合及其他结构性衍生品；仅允许 fully covered call 和 cash-secured put。covered call 必须由现有股票全额覆盖，行权价应是本来愿意减仓的价格；cash-secured put 必须在组合内预留全部行权资金，行权价应是本来愿意买入的价格。权利金不能成为主要理由，也不能用于掩盖现金不足。平仓用于降低风险时允许；roll 或重新开仓均视为新的投资决策，必须重新检查 thesis、估值、仓位和现金约束。被行权应默认接受，不能为回避原先同意的买卖价格而机械展期。
- **流动性纪律兜底“不减持”**：不减持 + 只加不减的组合结构，一旦被迫用钱就会在低点被动卖出，所以必须始终保留与负债/应急支出匹配的现金或流动性缓冲。
- **系统性风险下可以提高现金**：极端环境不强求满仓，先活下来。

---

## 7. 复盘原则

- **过程优先，结果验证**：先评判决策是否遵守原则，再用结果检验认知。
- **组合绩效默认使用 TWR**：评价组合管理能力、跨期表现和相对基准时以 TWR 为主；MWR 仅用于补充观察入金时点与个人资金体验，绝对盈亏另行列示。TWR 与 MWR 的差异本身不能证明择时能力，相关判断必须结合带日期的外部资金流和反事实检验。
- **带入当时信息集**：复盘不能用事后才知道的信息羞辱过去，但要区分“不知道”和“应该知道却忽略”。
- **审查买入理由的来源**：复盘时区分“当初的判断来自生意理解”还是“来自好感、使用体验、别人的收益或怕错过”；后者不是错，但必须在入场前被转换成 thesis 才能执行。
- **重大决策 30 天内复盘**：至少写清原始 thesis、当时 IC、预期 vs 实际、哪条原则被遵守/违反、下次改什么。
- **开始为不利事实找理由时，先停下来复盘**：回看原始 thesis、收益来源、代理变量和 IC。
- **公开表达不是风控替代品**：写文章能提高冲动成本，但真正的风控仍是 thesis、IC、仓位和现金纪律。
